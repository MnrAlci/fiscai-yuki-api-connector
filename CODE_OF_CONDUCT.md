# Code of conduct

We want this project to be a respectful, harassment-free place for everyone.

**Do:** be kind and constructive, assume good intent, give specific feedback on the work, and respect other people's time and privacy.

**Don't:** harass, insult, discriminate or publish other people's private information. Never post real Yuki keys, client names or accounting data in issues or pull requests.

Maintainers may edit or remove comments, issues and contributions that break these rules and may block repeat offenders. To raise a concern, use a private report through GitHub (Security tab, "Report a vulnerability") or contact the maintainer through his GitHub profile.
