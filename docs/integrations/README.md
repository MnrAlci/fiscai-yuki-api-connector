# Integrations

FISCAi Yuki API Connector is a plugin for Grok Bot and a standard MCP stdio server. These platforms can use it too, or complement it.

| Platform | What it is | Guide | Example |
|---|---|---|---|
| AgentMail | Mailboxes for AI agents (companion server, for example for a KPI mail draft) | [agentmail.md](agentmail.md) · [NL](agentmail.nl.md) | [agentmail-hosted.mcp.json](../../examples/agentmail-hosted.mcp.json), [agentmail-stdio.mcp.json](../../examples/agentmail-stdio.mcp.json) |
| Hermes Agent (Nous Research) | Open-source agent with native MCP | [hermes.md](hermes.md) · [NL](hermes.nl.md) | [hermes.config.yaml](../../examples/hermes.config.yaml) |
| OpenClaw | Agent gateway with MCP registry | [openclaw.md](openclaw.md) · [NL](openclaw.nl.md) | [openclaw.mcp.json](../../examples/openclaw.mcp.json) |

None of these has a Yuki-specific plugin from us: they use the same MCP server. Formats were checked against each project's official docs on 2026-11-20 and not tested live; follow their current docs (verify current docs). Nothing here needs a paid plan from us, and we register no accounts for you.
