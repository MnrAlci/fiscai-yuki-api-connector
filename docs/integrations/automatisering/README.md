# Automation

Automation tools can act on the export files or, when self-hosted, talk to the MCP server. n8n self-hosted is the privacy-friendly option; cloud tools only see what you put in a synced folder.

| Tool | Pricing/licence | Official site |
|---|---|---|
| [Zapier](zapier.md) | commercial, free tier may exist | https://zapier.com |
| [Make](make.md) | commercial, free tier may exist | https://www.make.com |
| [n8n](n8n.md) | source-available/self-hostable with paid plans: licence and pricing verifieer actuele regel | https://n8n.io |
| [Microsoft Power Automate](power-automate.md) | commercial, some use included with Microsoft 365 plans (verify) | https://www.microsoft.com/power-platform/products/power-automate |
| [Pipedream](pipedream.md) | commercial, free tier may exist | https://pipedream.com |
| [IFTTT](ifttt.md) | commercial, free tier may exist | https://ifttt.com |

Nederlandse samenvatting: automatiseringstools lezen de exportmap (of een gesynchroniseerde kopie) en krijgen nooit de Yuki-sleutel. n8n zelf gehost is de privacyvriendelijke keuze. Niets wordt automatisch verstuurd zonder menselijke bevestiging.
