# Document generation

Ten generators that turn the exports (or Grok Bot's text) into PDF, DOCX or a site. All run on your own computer and none is a paid service by default. Licences are quoted only where the project's repository states them; otherwise: verifieer actuele regel.

| [Docusaurus](docusaurus.md) | verifieer actuele regel | https://docusaurus.io | `examples/templates/docusaurus-kpi.md` |
