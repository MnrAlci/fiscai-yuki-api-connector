# Integraties

FISCAi Yuki API Connector is een plugin voor Grok Bot en een standaard MCP-stdioserver. Deze platformen kunnen hem ook gebruiken of aanvullen.

| Platform | Wat het is | Gids | Voorbeeld |
|---|---|---|---|
| AgentMail | Mailboxen voor AI-agents (aanvullende server, bv. voor een KPI-mailconcept) | [agentmail.nl.md](agentmail.nl.md) · [EN](agentmail.md) | [agentmail-hosted.mcp.json](../../examples/agentmail-hosted.mcp.json), [agentmail-stdio.mcp.json](../../examples/agentmail-stdio.mcp.json) |
| Hermes Agent (Nous Research) | Open-source agent met native MCP | [hermes.nl.md](hermes.nl.md) · [EN](hermes.md) | [hermes.config.yaml](../../examples/hermes.config.yaml) |
| OpenClaw | Agent-gateway met MCP-register | [openclaw.nl.md](openclaw.nl.md) · [EN](openclaw.md) | [openclaw.mcp.json](../../examples/openclaw.mcp.json) |

Geen van deze heeft een Yuki-specifieke plugin van ons: ze gebruiken dezelfde MCP-server. De formaten zijn op 20/11/2026 gecontroleerd in de officiële documentatie van elk project en niet live getest; volg hun actuele documentatie (verify current docs). Er is geen betaald abonnement van ons nodig en wij registreren geen accounts voor u.
