# Documentation

> **Belgium.** Made for Belgian accountants and bookkeepers (Belgian chart of accounts MAR, Belgian VAT). Outside Belgium, check the local rules yourself.

FISCAi Yuki API Connector is a plugin for Grok Bot (recommended install: see the [README](../README.md#install-in-grok-bot-recommended)). It also works in other MCP clients (Cursor, Claude, Copilot, Windsurf ...).
